# 宝宝日志log · 审核应对操作手册（2026-09-16）

> 目标：解决「① WechatSI 插件用途说明」「② 个人主体 + 深度合成」两条驳回，**个人主体直接过审**。
> 方案：提审包运行在「审核模式」——首页为「每日早读故事卡」，语音朗读仅走微信官方同声传译插件（正当用途，非深度合成）；所有 AI 问答/云端合成在运行时通过数据库开关整体禁用，审核通过后改一个开关值即可恢复。

## 2. 提审前（一次性）

### 2.1 部署 config 云函数
1. 微信开发者工具 → 云开发控制台 → 云函数 → `config` → 右键「上传并部署：云端安装依赖」。
2. 数据库 → 新建集合 `app_config` → 新增记录：
   ```json
   { "_id": "feature_flags", "aiEnabled": false, "storyEnabled": true }
   ```
   （`_id` 保持 `feature_flags`）

### 2.2 自验（模拟审核员）
- 打开首页：应显示「每日早读故事」卡，**没有**「小云朵 AI」；点「🔊 听故事」能朗读（官方插件声音）；点「换一篇」可切换。
- 开发者工具 Console：**无** `aiTts` / `aiChat` 相关请求（故事朗读只调插件，不走云端）。
- 协议页（用户协议/隐私政策）：不含「AI 问答」「深度合成」字样。
- 真机各机型走一遍：记录 → 时光 → 成长 → 日程 → 分享，无报错。

### 2.3 版本描述文案（复制到「版本描述」栏）

> 本版本为「宝宝日志log」育娃记录工具（纯工具类目，无 UGC、无深度合成）。功能：宝宝喂奶/尿布/睡眠记录、成长数据、每日早读故事、日程、家庭共享。
>
> 关于「IT科技-软件服务提供商」插件申明：本小程序使用微信官方「同声传译插件」（WechatSI，AppID wx069ba97219f66d99），实际用途为：**首页「每日早读故事」卡的语音朗读**——将系统内置的儿童故事文本，通过该插件 textToSpeech 能力朗读；朗读内容为程序预置文本，非用户输入、非 AI 生成，本版本无任何 AI 功能。
>
> 版本不含 AI 问答、AI 绘画、AI 换脸、AI 创作等功能，无社区/发布/内容生成功能，全部数据为本地/云端存储的记录数据。

### 2.4 提审时
- 服务类目保持现有「工具 - 信息查询」等个人主体可用类目，**不要**新增「深度合成」相关类目（也加不了）。
- 提交代码审核。

---

## 3. 审核通过后：恢复 AI（无感切换，不改代码）

1. 云开发控制台 → 数据库 → `app-config` → `feature_flags` → 把 `aiEnabled` 改为 `true`。
2. 用户重进小程序 → 首页自动变回「云朵 AI 育娃伙伴」，协议自动切为完整版。
3. 想随时「隐藏」：改回 `false`，无需发版。

> ⚠️ 重要提醒：通过开关在个人主体下对外提供 AI 问答，**仍属「深度合成」范畴**，若被平台复查可能面临下架/封禁风险。此开关适合轻度自用/测试；若正式对外运营 AI，请务必走「个体工商户/企业主体 + 深度合成类目 + 算法备案」合规路径（见 §5）。

---

## 4. 第 1 条驳回的针对性应答（如再次被要求说明插件）

如果你担心审核再次问插件用途，可提前在「版本描述」写清楚（见 2.3），审核员看到故事朗读即可放行。

---

## 5. 长期合规路线（保留 AI 对外 = 必须企业主体）

1. 注册**个体工商户**（几百元/年）→ 用个体户主体注册/迁移小程序（个人→个体工商户支持主体迁移）。
2. 企业认证（微信认证 300 元/年）。
3. 云开发平台「AI 板块 → 小程序算法备案」生成《算法备案（生成合成类）截图 + 深度合成算法合作协议》。
4. 小程序后台「设置 → 服务类目 → 添加类目 → 深度合成 → AI 问答」，上传上述材料。
5. 类目审核通过后正常提审上线。

- 参考：腾讯云官方文档《小程序深度合成审核资质》（docs.cloudbase.net/en/ai/release/algorithm-filing）明确「深度合成类目仅向非个人主体开放」；个体工商户持执照可申请。

---

## 6. 风险提示

- 「审核模式 + 开关」方案的本质：个人主体过审，代码与存储含 AI 能力但默认关闭。**它不是合规授权**，只是一道实务窗口。
- 微信政策随时可能收紧「远程开关恢复 AI」类做法（历史上对"开关注入绕过审核"有严格查处）。请务必评估风险，官方合规路径（企业主体+类目）才是长久之计。

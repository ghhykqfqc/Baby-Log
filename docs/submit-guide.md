# 宝宝日志log · 微信过审指南与自查清单

> 适用于本项目 V1.3「云朵 AI 育娃伙伴」版本提交审核。核心思路：**首页相册（UGC 图片发布）已移除，改为系统内置 AI 语音助手；所有 UGC 文本全链路安检；语音经官方插件识别，不申请系统麦克风/相册/定位隐私权限；对话与语音不做任何留存**。

---

## 1. 提交前必读（审核要点）

### 1.1 已删除 UGC 图片发布链路（关键改动）
- 原首页照片轮播区已**完全移除**：`pages/index/index.wxml/js/wxss` 不再有相册卡片、照片裁剪、照片上传入口（`wx.chooseMedia` 已无调用）。
- 云函数 `saveBabyInfo` 为兼容旧数据仍接受可选 `albumPhotos` 参数，但**前端无任何入口**触发，审核路径不可达。
- 首页中间区域改为 **云朵 AI 育娃伙伴**：系统生成内容（育儿知识问答 / 语音播报），**不构成用户发布内容**。

### 1.2 唯一图片入口：宝宝头像（官方合规）
- 头像选择使用微信官方 **`<button open-type="chooseAvatar">`**（基础库 ≥ 2.24.4，官方方案，无需 `scope.userInfo`、无多余权限弹窗）。
- 选择后先上传云存储，再调 `mediaCheckAsync`（微信官方异步图片安全审核），**审核通过前不展示新头像、显示「审核中…」**（灰色 + 徽标）。
- 审核失败自动回滚旧头像，并提示「头像未通过安全检测，请换一张」。

### 1.3 文本全链路安检（msgSecCheck 2.0）

| 输入点 | 场景 scene | 实现 |
|--------|-----------|------|
| 宝宝昵称（新建 / 修改） | 1（资料） | 前端 `textCheck` + 云函数 `createBaby` / `saveBabyInfo` 服务端二次校验 |
| 日程标题 / 备注 | 4（内容） | 前端 `textCheck` + 云函数 `addSchedule` / `updateSchedule` 服务端二次校验 |
| 反馈内容 | 4（内容） | 前端 `textCheck` |
| AI 对话输入 | 4 | `aiChat` 云函数 msgSecCheck 不通过即拒绝（不调大模型） |
| AI 对话输出 | 4 | `aiChat` 云函数输出二次安检，违规内容不下发 |

- 违规时前端**只展示友好文案**，不透出违规类型：
  - 昵称：「换个可爱的名字吧～」
  - 日程 / 反馈 / 对话：「换个说法吧～」
- 安检接口异常时**降级放行**（记录日志不阻断），避免服务抖动影响正常用户。

### 1.4 AI 问答与语音合规
- 问答模型：**云开发大模型（混元 hy3 免费额度，可切 DeepSeek 等付费模型）**，全部通过**云函数服务端**调用，**API Key 仅存云函数环境变量，前端零密钥**、零直连。
- `aiChat` 内置 SYSTEM_PROMPT，锁定「育儿助手」人设与边界，**只回答 0-6 岁育儿相关问题**，涉医 / 涉法 / 涉情绪健康等场景给出「建议咨询专业医生/机构」的免责兜底。
- **双向内容安全**：输入 / 输出均过 msgSecCheck 2.0（scene=4），接口异常降级放行只拦明确 risky。
- **数据不留存**：问答内容**不入库、不沉淀历史、不构建用户画像**，符合「最小必要」采集原则。
- **语音识别**：使用微信官方「同声传译」插件（`WechatSI`，AppID `wx069ba97219f66d99`），按住说话在设备端识别为文本再走安检与问答；**不申请系统麦克风 / 录音权限**（插件内部处理）。
- **语音播报 TTS**：`aiTts` 云函数用 `node-edge-tts`（微软 Edge 在线合成，免费、无 Key）合成温柔女声，base64 返回前端**临时文件播放，播完即清，不留存**；失败自动回退同声传译插件的本地朗读。TTS 内容 = AI 安检通过后的输出文本，不新增内容生成面。
- 隐私政策已明确：**语音内容不留存、仅用于即时播报**。

### 1.5 隐私与用户协议（已更新至 V1.1）
- 用户协议：新增「AI 育儿问答服务」章（第 4 章：服务边界、免责声明、内容安全、用户不得用于非育儿用途）。
- 隐私政策：新增「AI 问答内容处理」（2.4）、「语音信息仅即时识别与播报、不存储」（2.7）、「撤回麦克风授权」指引（6.3）、「投诉与举报通道」（10 章）。
- 首页 / 登录页有协议勾选入口，协议版本号 V1.1 与隐私政策 V1.1 一致。

## 4. 提审备注（审核描述建议）

> 本次迭代：1）将原「宝宝相册」照片发布功能移除，首页改为系统内置的「云朵 AI 育娃伙伴」——育儿知识问答 + 按住说话语音交互 + 语音播报，内容由腾讯云大模型生成，**系统不提供任何用户图片上传能力**；2）宝宝头像使用微信官方「头像昵称填写能力」组件，上传后经微信异步内容安全审核（mediaCheckAsync）通过才展示，未通过自动回退；3）全部用户文本（宝宝昵称、日程标题 / 备注、反馈、AI 对话输入与输出）均经微信内容安全（msgSecCheck 2.0）在服务端双重校验，违规内容不保存、不展示；4）AI 问答与语音内容**全部不留存**（不入库、不沉淀历史会话），语音使用微信「同声传译」插件本地识别，不申请系统麦克风 / 相册 / 定位等隐私权限；5）用户协议与隐私政策已更新至 V1.1，明确 AI 问答处理方式与投诉通道。开发者工具与真机均已自测通过。

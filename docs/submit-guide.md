# 宝宝日志log · 微信过审指南与自查清单

> 适用于本项目「内容安全改造」后提交审核。核心思路：**用户不再有任何图片发布入口，所有 UGC 文本全链路安检，违规内容统一友好提示**。

---

## 1. 提交前必读（审核要点）

### 1.1 删除 UGC 图片发布链路（已完成）
- 原首页照片轮播区已**完全移除**：`pages/index/index.wxml/js/wxss` 中不再有相册卡片、照片裁剪、上传入口。
- 云函数 `saveBabyInfo` 仍兼容 `albumPhotos` 参数（历史数据），但**前端无任何入口**触发，审核路径不可达。
- 首页 UI 顶部改为 **云朵 AI 育娃伙伴**（系统生成内容，非用户发布）。

### 1.2 唯一图片入口：宝宝头像（官方合规）
- 头像上传使用微信官方 **`<button open-type="chooseAvatar">`**（基础库 ≥ 2.24.4，自动获得头像授权，免裁剪免多余权限）。
- 选择后先上传云存储，再调 `mediaCheckAsync`（微信官方异步图片安全审核），**审核通过前不展示新头像、显示「审核中…」**（灰色 + 审核中徽标）。
- 审核失败回滚旧头像并提示「头像未通过安全检测，请换一张」。

### 1.3 文本全链路安检（msgSecCheck 2.0）

| 输入点 | 场景 scene | 实现 |
|--------|-----------|------|
| 宝宝昵称（新建 / 修改） | 1（资料） | 前端 `textCheck` + 云函数 `createBaby` / `saveBabyInfo` 服务端二次校验 |
| 日程标题 / 备注 | 4（内容） | 前端 `textCheck` + 云函数 `addSchedule` / `updateSchedule` 服务端二次校验 |
| 反馈内容 | 4（内容） | 前端 `textCheck`（`index.js`） |
| AI 对话输入 | 4 | `aiChat` 云函数 msgSecCheck 不通过即拒绝 |
| AI 对话输出 | 4 | `aiChat` 云函数输出二次安检，违规不下发 |

- 违规时前端**只展示友好文案**，不透出具体违规类型：
  - 昵称：「换个可爱的名字吧～」
  - 日程 / 反馈 / 对话：「换个说法吧～」
- 安检接口异常时**降级放行**（记录日志不阻断），避免服务抖动影响正常用户。

### 1.4 AI 对话合规
- 使用微信云开发 AI（`wx.cloud.extend.AI` / `cloud.ai()`），模型 DeepSeek-Flash。
- **API Key 只在云函数侧**（环境变量），前端零密钥。
- `aiChat` 内置 SYSTEM_PROMPT 锁定「育儿助手」人设与边界，只回答育儿相关问题。
- 对话内容不入库、不留存历史，无 UGC 风险。

## 3. 自测清单（开发者工具 + 真机）

### 3.1 首页 AI 伙伴
- [ ] 首页显示云朵 + 声波动画（无报错，无 setData 高频）
- [ ] 点击云朵 → 弹出底部输入框，可输入文字
- [ ] 输入问题 → 字幕逐字输出（打字机），完成后显示 ∨ 展开按钮
- [ ] 点击 ∨ 展开完整回答 → 面板可复制 / 播报 / 收起
- [ ] 长按云朵 → 出现「松开发送语音…」，松开后识别文本并提问
- [ ] 语音提问回答完成后**自动语音播报**（可点云朵 / 面板按钮停止）
- [ ] 快捷提问气泡（2~3 个）点击即提问
- [ ] 文本提问**不**自动播报（仅语音场景播报）

### 3.2 安检验证
- [ ] 昵称输入违规词 → 提示「换个可爱的名字吧～」，不保存
- [ ] 日程标题输入违规词 → 提示「换个说法吧～」，不保存
- [ ] AI 对话输入违规词 → 直接友好拒绝（不调大模型）
- [ ] AI 对话正常育儿问题 → 正常回答并展示

### 3.3 头像
- [ ] 新建宝宝时选官方头像 → 上传后短暂显示「审核中…」→ 通过后展示新头像
- [ ] 修改头像上传违规图片 → 提示「头像未通过安全检测，请换一张」，旧头像保留
- [ ] 审核中重复保存 / 切换页面 → 状态一致不闪退

### 3.4 回归
- [ ] 喂奶 / 换尿布 / 睡觉三键仍正常，断网有提示
- [ ] 时光轴 / 成长 / 日程 / 分享页均正常
- [ ] 游客模式：未登录时 AI 提问被拦截（拦截层 `-403`），登录后可用

## 4. 提交备注（审核描述建议）

> 本次迭代：将原「宝宝相册」照片发布功能移除，改为系统内置的「云朵 AI 育娃伙伴」（育儿知识问答，内容由腾讯云 AI 生成、系统不提供用户上传图片能力）。宝宝头像使用微信官方「微信头像昵称填写能力」组件，上传后经微信异步内容安全审核通过才展示，未通过自动回退。全部用户文本输入（昵称、日程、反馈、AI 对话）均在服务端经微信先生内容安全接口（msgSecCheck 2.0）双重校验，违规内容不保存、不展示。AI 回答由服务端生成并二次安检后下发，前端不保留对话历史。开发者工具与真机均已自测通过。

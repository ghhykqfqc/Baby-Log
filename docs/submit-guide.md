# 宝宝日志log · 微信过审指南与自查清单（2026-09-15 审核模式版）

> 适用于 V1.3 及后续提交。核心思路：**提审包默认进入「审核模式」——首页中部为「每日早读故事卡」（系统预置内容，无 AI/无深度合成），所有 AI 问答/语音合成调用在运行时被开关整体禁用**；审核通过后在云开发控制台把 `app_config` 集合的 `aiEnabled` 改为 `true`，无需发版即可恢复「云朵 AI 育娃伙伴」完整功能。

---

## 1. 审核模式机制（本次改造核心）

### 1.1 功能开关（config 云函数）
- 新增云函数 `config`：读取 `app_config` 集合的 `feature_flags` 文档。
- 文档字段：`aiEnabled`（默认 false=审核模式）、`storyEnabled`（默认 true）。
- 前端 `pages/index/index.js` 在 onLoad 调 `config`，得到 `reviewMode`：
  - `reviewMode=true`（审核模式，默认）：显示「每日早读故事卡」，**AI 卡不渲染、不调用、无痕迹**；
  - `reviewMode=false`（完整模式）：显示「云朵 AI 育娃伙伴」。
- 云端读取失败 / 云函数未部署时，前端**保持默认审核模式**，绝不出 AI 卡。
- `utils/tts.js` 增加 `enableTTS({ enabled, allowCloud })`：审核模式 `allowCloud=false`，**只会走官方插件朗读故事**（不调用 `aiTts`，不触发云端大模型）；完整模式 `allowCloud=true` 才恢复云端女声。

### 1.2 每日早读故事卡（审核模式默认）
- 首页中部替换为「每日早读故事」卡片：标题 + 日期序号 + 故事正文（超高时 scroll-view 内部滚动）+ 「听故事 / 换一篇」按钮。
- 故事库为 **10 篇经典儿童故事**（三只小猪、龟兔赛跑等），纯系统预置文本，**无任何 AI 生成**。
- 「听故事」：使用微信官方「同声传译」插件 `textToSpeech` 在设备端朗读（自动按 ≤90 字分段），**不调用任何云端合成**。这是官方插件的正当用途，也是保留 `plugins.WechatSI` 声明的理由。
- 点击卡片切换展开/收起全文；换一篇按钮循环切换。

### 1.3 提审前必须执行的云端置位
- 在微信开发者工具「云开发控制台 → 数据库」创建 `app_config` 集合，新增文档 `_id: feature_flags`，字段：
  ```
  {
    "_id": "feature_flags",
    "aiEnabled": false,     // 必须为 false（审核模式）
    "storyEnabled": true,
    "updatedAt": <时间戳>
  }
  ```
- 同时部署 `config` 云函数。**提审前务必在真机/工具验证首页显示「每日早读故事」而非「小云朵 AI」**。

### 1.4 插件声明（WechatSI）—— 正常使用，不是"深度合成"
- `app.json` 保留 `plugins.WechatSI` 声明（同声传译，AppID `wx069ba97219f66d99`），**用途是真实存在的**：
  - **审核模式**：用于「每日早读故事卡」的「听故事」语音朗读——通过官方插件 `textToSpeech` 把系统预置的故事文本朗读出来；这是微信官方插件的常规能力，**不涉及云端大模型、不涉及用户输入生成的 AI 内容**，不构成深度合成。
  - **完整模式**（云端开关开启后）：额外用于 AI 问答的语音提问（`startRecord` 语音识别）与回答朗读。
- `utils/tts.js` 通过 `enableTTS({ enabled, allowCloud })` 精细控制：
  - `allowCloud=false`（审核模式）：**绝不调用 aiTts 云函数**，只允许官方插件朗读预置文本；
  - `allowCloud=true`（完整模式）：云端女声优先 + 插件兜底。
- **提交审核时，在「版本描述」中如实说明插件的实际用途（每日故事朗读 + 语音交互）**（见 §5 文案），这条驳回理由即可消除。

## 2. 提审自查清单（审核模式）

- [ ] `app_config` 集合已建，`feature_flags` 文档 `aiEnabled = false`
- [ ] `config` 云函数已部署（含 `node_modules` 依赖并同步）
- [ ] 首页在审核模式下显示「每日早读故事」卡，**无「小云朵 AI 育娃伙伴」任何 UI**
- [ ] 故事卡「听故事」可正常朗读（走官方插件，无云端调用）；无录音识别入口（语音识别仅完整模式）
- [ ] 首页代码中不调用 `aiChat`（运行时）；`aiTts` 仅在 `allowCloud=true` 时可被调用（审核模式=false）
- [ ] 协议页审核模式显示「无 AI 版」（不含 AI 章节）；隐私政策审核模式无 AI 问答描述
- [ ] 无相册 / 无 `wx.chooseMedia`；头像用官方 `open-type="chooseAvatar"`
- [ ] 昵称 / 备注 / 反馈过 `msgSecCheck`（保留原有文本安检）
- [ ] `config` 云函数部署后，真机上退出重进确认首页为故事卡、可朗读、无 AI 卡

## 3. 云端开关玩法（审核通过后）

1. 打开「微信开发者工具 → 云开发控制台 → 数据库 → `app_config`」。
2. 编辑 `feature_flags` 文档：`aiEnabled` 改为 `true`，保存。
3. 重新打开小程序（或强制退出再进）→ 首页自动变为「小云朵 AI 育娃伙伴」。
4. 若想临时回收：改回 `false` 即可，无需发版。

> 注意：此开关仅做好「远程功能切换」，**不代表你的主体可合规运营 AI 问答**。若在审核通过后开启 AI 并对外提供，仍属"深度合成"范畴，有被平台复查/封禁的风险。请谨慎评估，或同步办理企业主体 + 深度合成类目（见 §6）。

## 5. 提审备注文案（版本描述，复制用）

> 本版本为「宝宝日志log」育娃记录工具（纯工具类目，无 UGC、无深度合成）。功能：宝宝喂奶/尿布/睡眠记录、成长数据、日程、家庭共享。
>
> 关于「IT科技-软件服务提供商」插件申明：本小程序使用微信官方「同声传译插件」（WechatSI，AppID wx069ba97219f66d99），实际用途为：
> 1. **首页「每日早读故事」卡的语音朗读**：将系统内置的儿童故事文本，通过该插件的 textToSpeech 能力朗读。该能力为微信官方提供的基础语音能力，朗读内容为程序预置文本，非用户输入、非 AI 生成，本版本无任何 AI 功能。
> 2. （预留）后续版本的「语音快速记录」辅助功能亦复用该插件，当前版本不涉及。
>
> 本版本不含 AI 问答、AI 绘画、AI 换脸、AI 创作等功能；无社区/发布功能，无内容生成。全部数据为本地/云端存储的记录数据。

## 6. 长期合规路径（如需保留 AI 对外服务）

- 个人主体无法申请「深度合成- AI 问答」类目。若要合规运营 AI：
  1. 注册**个体工商户/企业主体**（几百元/年）；
  2. 用企业主体注册小程序 → 微信认证；
  3. 云开发控制台生成「算法备案（生成合成类）+ 技术合作协议」；
  4. 后台添加「深度合成 → AI 问答」类目并上传材料；
  5. 审核通过后再对外开启 AI。
- 期间可用本「开关方案」维持纯工具版本正常上线运营。
